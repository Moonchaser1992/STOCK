## 一、目标

将用户多年总结的A股选股模型自动化：每日收盘后自动筛选，输出次日观察池，微信推送提醒。

---

## 二、市场范围

- 创业板（300/301 开头，涨跌幅 20%）
- 科创板（688 开头，涨跌幅 20%）
- 北交所（8 开头，涨跌幅 30%）

---

## 三、筛选模型

### 第0层：基础过滤

| 条件 | 说明 |
|---|---|
| 板块 | 创业板 + 科创板 + 北交所 |
| ST/ST* | 排除 |
| 上市天数 | ≥ 100天（排除次新股） |
| 总市值 | < 400亿 |

### 第1层：涨幅初筛

分别按以下三个周期排序，各取前30名，去重合并：

| 排名维度 | 说明 |
|---|---|
| 单日涨幅 | 当日涨跌幅排名 |
| 5日涨幅 | 近5个交易日累计涨幅 |
| 10日涨幅 | 近10个交易日累计涨幅 |

**原理**：涨幅进入前列，说明股性被激活，市场关注度提升。

### 第2层：量价形态筛选

在初筛股票池中，判断 10-15 个交易日内的量价形态：

- **放量涨阶段**：成交量放大，K线抬升
- **缩量调阶段**：成交量缩小，K线回调
- **形态判定**（模糊实现）：
  - 将窗口分为前后两半
  - 前半段均价线趋势向上 + 均量放大
  - 后半段均价线趋势走平或向下 + 均量缩小
  - 前半段均量 > 后半段均量 × 1.3

**原理**：放量涨确认资金介入，缩量调说明在消化获利盘而非出货。

### 成交量修正

涨停股当日成交量失真（涨停后无成交），按涨停前量比估算全天真实量：

- 若涨停且当日量远低于前几日均值 → 按涨停前日均量 × 系数推算

## 四、技术架构

### 方案

Python CLI + Flask Web + Git 同步

### 项目结构

```
STOCK/
├── data/
│   ├── cache/              # akshare 日K线缓存（.gitignore）
│   └── results/            # 每日筛选 CSV（Git 同步）
├── engine/
│   ├── fetcher.py          # 数据获取：akshare 封装 + 涨停量修正
│   ├── screener.py         # 通用筛选框架
│   └── conditions.py       # 用户选股条件（独立可配）
├── notifier/
│   └── wechat.py           # 微信推送（PushPlus）
├── web/
│   ├── templates/
│   │   ├── index.html      # 主页：日期选择 + 结果表格
│   │   └── detail.html     # 个股详情 + K线图
│   ├── static/
│   └── routes.py           # Flask 路由
├── config.py               # 集中配置
├── run.py                  # 每日一键入口
├── app.py                  # Flask Web 入口
├── sync.sh                 # Git 同步辅助脚本
└── requirements.txt
```

### 数据流

```
收盘后触发 run.py
  → git pull（同步远端结果）
  → fetcher.py 拉取全量日K线（增量缓存）
  → 第0层过滤（板块/ST/市值/上市天数）
  → 第1层：5日/10日/单日涨幅排名各Top30去重
  → 第2层：量价形态筛选
  → 结果写入 data/results/YYYY-MM-DD.csv
  → wechat.py 推送微信消息
  → git add + commit + push（同步结果）
```

### 数据同步

- `data/cache/` 加入 `.gitignore`，不提交（太大）
- `data/results/` 纳入 Git，每台电脑跑前 pull、跑后 push
- 冲突策略：自动 push，失败则重试

### 定时触发

- Windows：任务计划程序，设 15:30（收盘后）
- 也可手动双击 `run.py`

## 五、Web 复盘页面

### 页面清单

| 页面 | 功能 |
|---|---|
| 主页（index） | 日期选择器 + 当日筛选结果表格（代码、名称、涨跌幅、形态标记） |
| 个股详情（detail） | K线图 + 各项指标标注 |
| 月度统计 | 按月的选出数量、次日涨跌统计、胜率 |

### 技术选型

- Flask + Jinja2 模板渲染
- K线图：mplfinance 或 pyecharts（服务端渲染图片）

---

## 六、微信推送

- 服务：PushPlus 或 Server酱
- 内容：股票列表 + 关键数据摘要 + 本地 Web 链接
- 频率：每日一次，筛选完成后推送
